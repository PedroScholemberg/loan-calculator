# loan-calculator

A web application for loan calculation and amortization scheduling, built as a
technical assessment for a Java developer position.

> **Project status — M0 (initialization).** The repository currently contains
> only the scaffolded backend and frontend projects generated by their official
> tools. No loan calculation, payment schedule, or API functionality has been
> implemented yet.

## Technology stack

| Layer          | Technology                                   | Status      |
| -------------- | -------------------------------------------- | ----------- |
| Backend        | Java 17, Spring Boot 4.0.9, Maven (Wrapper)  | Initialized |
| Backend        | Spring Web (MVC), Bean Validation            | Initialized |
| Backend tests  | JUnit 5 via Spring Boot test starters        | Initialized |
| Frontend       | React 19, TypeScript, Vite 8                 | Initialized |
| Frontend style | Tailwind CSS                                 | Planned     |
| Infrastructure | Docker, Docker Compose, Nginx                | Planned     |

> Spring Boot 4.0.9 is used because Spring Initializr no longer generates
> Spring Boot 3.x projects. Spring Boot 4.0 keeps Java 17 as its minimum
> supported version.

## Repository structure

This is a simple monorepo with two independently built applications. There is
no monorepo orchestration tool; each application uses its own build tooling.

```text
loan-calculator/
├── backend/            # Spring Boot API (Maven) — generated by Spring Initializr
│   ├── .mvn/           # Maven Wrapper configuration
│   ├── src/
│   │   ├── main/       # Application sources and resources
│   │   └── test/       # Tests
│   ├── mvnw / mvnw.cmd # Maven Wrapper scripts
│   └── pom.xml
├── frontend/           # React + TypeScript SPA — generated by Vite
│   ├── public/
│   ├── src/
│   ├── index.html
│   ├── package.json
│   ├── package-lock.json
│   └── vite.config.ts
├── .gitignore
└── README.md
```

## Prerequisites

- **JDK 17** or newer (the backend is compiled with `--release 17`)
- **Node.js** `^20.19.0` or `>=22.12.0` with npm (required by Vite 8)

Maven doesn't need to be installed; the backend uses the Maven Wrapper.

## Backend

```bash
cd backend

# Build and run the tests
./mvnw clean verify        # Windows: mvnw.cmd clean verify

# Start the application (http://localhost:8080)
./mvnw spring-boot:run     # Windows: mvnw.cmd spring-boot:run
```

The backend currently contains only the generated application class and its
context-load test. No endpoints are exposed yet.

## Frontend

```bash
cd frontend

# Install dependencies from the lockfile
npm ci                     # or: npm install

# Start the development server (http://localhost:5173)
npm run dev

# Type-check and create a production build in dist/
npm run build

# Preview the production build locally
npm run preview

# Lint the sources
npm run lint
```

The frontend currently shows the default Vite + React sample page. It doesn't
talk to the backend yet.

## Running with Docker Compose (planned)

Containerization isn't implemented yet. A later milestone will add
Dockerfiles for both applications, an Nginx setup for serving the frontend,
and a `docker-compose.yml` so the whole stack can be started with a single
command. Until then, run each application locally as described above.
